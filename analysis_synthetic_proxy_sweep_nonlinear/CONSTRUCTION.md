# Nonlinear synthetic proxy sweep

This study is a self-contained nonlinear counterpart of
`analysis_synthetic_proxy_sweep_linear`. It draws its own Gaussian roots,
treatment, outcomes, truth, row IDs, and train/query split. Within each
dimension, those quantities are shared across the complete proxy-strength grid;
only `W` and `Z` change with proxy strength. The observed `X`, `W`, and `Z` are
mapped coordinate-wise through

```text
g(t) = (t + 0.25 t^3) / sqrt(3.4375).
```

For a standard Gaussian input, `g` has population mean zero and variance one.
Its derivative is strictly positive, so it is invertible. Consequently the
sigma-fields generated by each raw and transformed proxy block are identical:
the grid value `s` remains the exact population correlation-ratio R² of `U`
predicted optimally from `(W,Z)`. OLS R² on the transformed proxy scale is
reported only as a descriptive diagnostic and is not the controlled quantity.

The latent Gaussian data-generating process is

```text
X*, U, eps_W, eps_Z, eps_Y ~ independent standard Gaussians
logit P(A=1 | X*,U) = 0.5 sum(X*)/sqrt(d) + 1.25 sum(U)/sqrt(d)
Y(0) = 0.5 sum(X*)/sqrt(d) + 1.5 sum(U)/sqrt(d) + eps_Y
CATE(X*) = 0.5 + sum(X*)/sqrt(d)
Y(1)-Y(0) = CATE(X*) + 0.5 sum(U)/sqrt(d)
```

At target joint strength `s`, each raw proxy channel has
`q = s / (2-s)` and is generated as a rotated noisy measurement of `U`.
The saved covariates and proxies are `g(X*)`, `g(W*)`, and `g(Z*)`. Thus CATE
and the outcome/proxy bridge are nonlinear functions of the variables supplied
to estimators. This is deliberately an invertible observed-scale
reparameterisation: it changes functional difficulty without changing causal
information.

## Methods

Exactly three `CATE(X)` outputs are compared at context sizes 128, 512, 2048,
and 4096:

- **ProximalFM**, using `whole_1/best_model.ckpt` and one inference view.
- **P-Kernel-RF**, the benchmark P-learner with four-fold cross-fitted kernel
  bridges and a cross-validated random-forest final regression.
- **S-TabICL-WZ-MC64**, an S-learner on `(X,W,Z,A)` whose conditional treatment
  contrasts are averaged over a seed-0 sample of 64 aligned context `(W,Z)`
  pairs, drawn without replacement and shared by every query.

The TabICL curve is **marginalized proxy adjustment, not an identified backdoor
estimator**. Proximal completeness does not imply treatment ignorability after
conditioning on imperfect proxies. The global empirical integration law is
appropriate here only because the generator makes `(W,Z)` independent of `X`.

## Reproduction

The default build contains 12,000 rows at 20 strength levels for each dimension
in `{1,3,5}`. Generate it, run the three methods, and plot with:

```sh
uv run python generate_nonlinear_sweep.py
uv run python run_ablation.py --device mps
uv run python plot_results.py
```

For a small development example, choose a separate output directory and reduce
the rows, strength levels, dimensions, and runner contexts together:

```sh
uv run python generate_nonlinear_sweep.py \
  --output data_small --rows 500 --levels 3 --dimensions 1 --seed 7
uv run python run_ablation.py \
  --data-dir data_small --output-dir results_small --context-sizes 128 --device cpu
uv run python plot_results.py --results-dir results_small
```

`--rows` must leave enough context rows for the requested runner context sizes;
the generator reserves the final 20% for scoring. `--r2-min` and `--r2-max`
can also narrow the generated strength grid.

Generation records its complete recipe and output checksums. Successful fits are persisted
under `results/.fit_cache/`; changing the data, transform, method configuration,
checkpoint, numerical packages, device, or runner invalidates the cache.
Use `--force` to recompute every requested fit.
